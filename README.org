* Overview

blueutil.el is an Emacs package that provides a convenient interface for managing Bluetooth devices on macOS using the [[https://github.com/toy/blueutil][blueutil]] command-line utility. It allows you to list paired devices, connect/disconnect devices, and search for paired devices directly from Emacs.

* Prerequisites

+ macOS operating system
+ The ~blueutil~ command-line tool installed via Homebrew:
  #+BEGIN_SRC sh
    brew install blueutil
  #+END_SRC

** Installation

+ Clone the repository to your Emacs configuration directory:
  #+BEGIN_SRC sh
    git clone https://github.com/ginqi7/blueutil.el ~/.emacs.d/lisp/blueutil
  #+END_SRC

+ Add the directory to your ~load-path~ in your Emacs configuration:
  #+BEGIN_SRC emacs-lisp
    (add-to-list 'load-path "~/.emacs.d/lisp/blueutil")
  #+END_SRC

* Configuration

Load the package in your Emacs configuration:

#+BEGIN_SRC emacs-lisp
  (require 'blueutil)
#+END_SRC

** Variables

| Variable             | Default Value         | Description                    |
|----------------------+-----------------------+--------------------------------|
| ~blueutil-command~   | Path to blueutil binary | The command used to interact with Bluetooth |

* Features

+ ~blueutil-paired~ - List all paired Bluetooth devices
+ ~blueutil-connected~ - List all currently connected Bluetooth devices
+ ~blueutil-connect~ - Connect to a Bluetooth device by ID
+ ~blueutil-disconnect~ - Disconnect a Bluetooth device by ID
+ ~blueutil-search-paired~ - Interactive interface to search and manage paired devices

* Example

#+BEGIN_SRC emacs-lisp
  ;; List all paired devices
  (blueutil-paired)

  ;; List connected devices
  (blueutil-connected)

  ;; Connect to a device (use the device's address)
  (blueutil-connect "12-34-56-78-9a-bc")

  ;; Disconnect a device
  (blueutil-disconnect "12-34-56-78-9a-bc")

  ;; Interactive search - M-x blueutil-search-paired
  (blueutil-search-paired)
#+END_SRC
